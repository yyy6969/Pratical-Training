成绩管理系统 - 功能介绍文档
一、系统概述
该成绩管理系统是基于 C++20 模块特性开发的控制台应用程序，采用 PostgreSQL 数据库实现数据持久化，核心实现了学生、教师、课程的基础管理，以及教师排课、学生选课的核心业务逻辑。系统遵循面向对象设计思想，通过单例模式、继承、智能指针等特性保证代码的健壮性和可维护性。
技术栈

    开发语言：C++20（模块特性）
    数据库：PostgreSQL（pqxx 库）
    核心特性：智能指针（shared_ptr/weak_ptr）、单例模式、面向对象（继承 / 封装）
二、核心功能模块
1. 数据模型层
系统设计了基础数据模型，覆盖核心业务实体，各模型职责清晰：
2. 数据持久化层（数据库模块）
通过 operationToDB 类实现与 PostgreSQL 数据库的交互，核心功能：

    自动建表：初始化时自动创建 students/teachers/courses/user_course 四张表，包含字段约束（如性别仅支持 man/woman/unknown、年龄大于 0）；
    数据插入：支持学生、教师、课程的插入，避免重复 ID（ON CONFLICT DO NOTHING）；
    关联操作：实现学生 - 课程、教师 - 课程的关联存储，校验关联对象是否存在；
    连接管理：通过智能指针管理数据库连接，自动释放资源，避免内存泄漏。

3. 业务逻辑层
（1）查找模块（Broker）

    relationBroker：基类，提供课程 ID 查找通用方法；
    studentBroker：继承基类，实现学生 ID 查找；
    teacherBroker：继承基类，实现教师 ID 查找；
    核心作用：校验学生 / 教师 / 课程是否存在，为排课 / 选课提供前置校验。

（2）排课 / 选课模块

    Arrangement（教师排课）：单例模式，校验教师 / 课程存在性后，同步更新内存和数据库的教师 - 课程关联；
    Enrollment（学生选课）：单例模式，校验学生 / 课程存在性后，同步更新内存和数据库的学生 - 课程关联。

4. 交互层（UI 模块）
提供控制台交互界面，核心功能：

    系统初始化：创建数据库表、预置测试数据（默认教师 T001/T002、学生 S001/S002、课程 C001/C002）；
    主菜单交互：支持 6 类操作（添加教师 / 学生 / 课程、教师排课、学生选课、查看所有数据、退出）；
    输入校验：对整数（年龄 / 学分）、浮点数（学分）做输入校验，提示英文性别输入规范；
    数据同步：添加数据时，同时写入数据库和 System 内存列表，保证数据一致性。
三、核心操作流程
内存层：所有数据存储在 System 类的列表中，通过智能指针管理；
数据库层：所有操作同步写入数据库，断电 / 重启后数据不丢失；
操作原则：仅当数据库插入成功后，才更新内存数据，避免数据不一致。
四、使用说明
1. 环境准备

    安装 PostgreSQL 数据库，创建名为 sqlDB 的数据库，用户 yhr（密码 admin123）；
    安装 libpqxx 库（PostgreSQL C++ 客户端库）；
    支持 C++20 模块的编译器（如 GCC 11+）。

2. 操作步骤

    编译并运行程序，自动完成数据库初始化和测试数据预置；
    主菜单输入数字选择操作：
        1：添加教师（输入 ID、姓名、年龄、性别（man/woman/unknown））；
        2：添加学生（输入 ID、姓名、年龄、性别（man/woman/unknown））；
        3：添加课程（输入 ID、课程编号、课程名、学分）；
        4：教师排课（输入教师 ID、课程 ID，仅支持 1 名教师授 1 门课）；
        5：学生选课（输入学生 ID、课程 ID，支持选多门课）；
        6：查看所有数据（展示内存中教师 / 学生 / 课程列表）；
        0：退出系统（自动清理内存数据）。

五、关键特性总结

    数据持久化：基于 PostgreSQL 实现数据永久存储，支持关联约束和重复校验；
    内存安全：全程使用智能指针（shared_ptr/weak_ptr），避免内存泄漏和空指针访问；
    输入友好：对非法输入（非数字、无效性别）做校验和提示，提升用户体验；
    设计规范：采用单例模式（System/UI/Arrangement/Enrollment）、继承（Broker / 学生 / 教师）等设计模式，代码结构清晰；
